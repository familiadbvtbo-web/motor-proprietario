# Motor Proprietário

Projeto Android do Motor Proprietário.

## Segurança

- execução real desabilitada por padrão;
- paper trading obrigatório;
- nenhuma chave privada no APK;
- dados sensíveis não devem ser commitados.

## Build

O projeto usa Gradle e Android Studio.

Consulte `BUILD_STATUS.md` na raiz para o estado do build neste ambiente.
